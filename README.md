# Rama Krishna Mohanty — Bioinformatics Portfolio

A responsive single-page bioinformatics portfolio built with HTML, CSS and JavaScript for GitHub Pages.

## Files
- `index.html` — page content and sections
- `styles.css` — layout, typography, light/dark palettes and responsive styling
- `script.js` — theme toggle, mobile navigation and footer year
- `assets/hero-science.png` — the single shared homepage illustration, recolored with CSS in light mode

## Publish with GitHub Pages
1. Extract the ZIP archive.
2. Upload `index.html`, `styles.css`, `script.js`, `README.md`, and the entire `assets` folder to the root of your repository.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/(root)`, then save.

Keep the `assets` folder beside `index.html`; do not rename it.

## Before publishing
Replace `YOUR_EMAIL@example.com` with your professional email address and review all personal details. Project figures are linked from the public GitHub repositories and require an internet connection.


## Homepage artwork

The hero uses one transparent DNA illustration (`assets/hero-science.png`) layered directly into the homepage canvas, with no separate panel. The same source image is used in both themes: dark mode keeps its teal-and-gold colors, while light mode darkens the same artwork to deep emerald and gold with CSS. Keep the `assets` folder at the repository root when publishing.
