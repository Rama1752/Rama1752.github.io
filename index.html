PROJECT 01 / FEATUREDGENOMICS · WORKFLOW ENGINEERING
Open repository ↗

Reproducible WGS / WES germline variant-calling pipeline

A configurable Snakemake workflow designed to take paired-end sequencing reads through processing and germline variant calling to filtered VCF outputs.

Pipeline structure

FastQC and fastp quality checks and trimming, BWA-MEM alignment, duplicate marking, base quality score recalibration, GATK HaplotypeCaller, genotyping and hard filtering.

Reproducibility and outputs

WGS or WES mode is selected through configuration. The repository documents environment files, sample-sheet inputs, per-sample workflow outputs, mosdepth coverage summaries and MultiQC reports.

PROJECT 02 / FEATUREDTRANSCRIPTOMICS · DIFFERENTIAL EXPRESSION
Open repository ↗

Bulk RNA-seq analysis of inflammatory response

Exploring how IL-1β-associated inflammation changes gene expression in human chondrocytes, and how cyproheptadine treatment relates to those expression patterns.

Research context

The project uses the public GEO dataset GSE291878, with four conditions: DMSO control, cyproheptadine, IL-1β and combined cyproheptadine + IL-1β treatment (five samples per condition, as described in the repository).

Workflow explored

Raw SRA data preparation, FastQC and MultiQC quality checks, optional read trimming, HISAT2 alignment to GRCh38, SAMtools processing, alignment quality checks, feature counting, DESeq2 analysis and Hallmark pathway enrichment.

Analysis outputs

Principal component analysis, sample-distance and variable-gene heatmaps, volcano plots, gene-level comparisons and GSEA enrichment visualizations.

03 / RNA-seq PREPROCESSING↗

Raw data to feature counts

A step-by-step preprocessing tutorial following SRA data through FastQC, MultiQC, HISAT2 alignment, alignment checks and featureCounts. Uses the LCOR overexpression dataset in MCF7 and MDA-MB-231 cell lines.

The repository notes that this dataset has no biological replicates; it is presented here as a preprocessing workflow exercise, not as a robust differential-expression study.
